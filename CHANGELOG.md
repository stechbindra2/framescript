# Changelog

All notable FrameScript changes are documented here.

## 0.1.0 - 2026-10-06

Initial public alpha:

- deterministic FrameScript compiler and versioned timeline IR;
- Remotion project generation with assets, fonts, audio, video, and typed plugins;
- named cross-file modules and dependency-aware watch builds;
- Tree-sitter grammar, language server, and packaged VS Code extension;
- portable semantic source maps and source-enriched runtime failures;
- FFprobe metadata, cached loudness analysis, media validation, and scheduled audio ducking.

This release is an alpha. Renderer parity, backwards compatibility, and every production-media workflow are not yet guaranteed.
